# 独立游戏工作室官网 / 第一版

一个无构建依赖的静态官网原型，围绕成熟游戏工作室首页所需的信息架构设计。

## 预览

直接打开 `index.html`，或在本目录运行：

```powershell
python -m http.server 4173
```

然后访问 `http://localhost:4173`。

分享给其他成员的方法见 `SHARE.md`。

## 已实现

- 复古深空接收终端风格，但保留现代官网的信息层级与大面积游戏视觉
- 可持续扩展的作品目录；《深空接收机》是项目 001，并预留未来作品位置
- 项目概念、核心玩法、世界档案、工作室介绍、成员与联系模块
- 中文 / 英文切换、CRT 扫描线开关、玩法标签切换、概念图大图浏览
- 响应式桌面 / 平板 / 手机布局与 reduced-motion 支持
